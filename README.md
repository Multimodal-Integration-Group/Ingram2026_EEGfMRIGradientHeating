<h1 align="center">Reducing the Risk of Gradient-Induced EEG Hardware Heating During Simultaneous EEG-fMRI</h1>

This repository contains the code and data needed to reproduce the heating results and figures from the paper.

## Reproducing the results

All results and figures can be regenerated with the following command:

```bash
uvx snakemake --cores 1
```

This requires [uv](https://docs.astral.sh/uv/) to be installed.
